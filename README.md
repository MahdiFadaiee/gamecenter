# گیم‌سنتر

سامانه‌ی مدیریت یک گیم‌سنتر با Laravel 10 و MySQL.

## امکانات

- ثبت‌نام بازیکن، صفحه‌ی پروفایل عمومی و پنل عضو
- ثبت زمان بازی اعضا و صدور خودکار جایزه بر اساس ساعت بازی
- مدیریت بازی‌ها، جام‌ها، ثبت‌نام‌ها، برنامه و نتیجه‌ی مسابقه‌ها
- مدیریت بلاگ، صفحه‌های سایت و پیام‌های تماس
- قالب سایت بر پایه‌ی دمو موجود در `public/site/gamecenter`

## راه‌اندازی

1. وابستگی‌ها را نصب و فایل محیط را تنظیم کنید.
2. `DB_DATABASE=gamecenter` را همراه با مشخصات اتصال MySQL قرار دهید.
3. برای ساخت اولین مدیر، `SEED_ADMIN_EMAIL` و `SEED_ADMIN_PASSWORD` را در محیط تنظیم کنید. گذرواژه باید دست‌کم ۱۶ نویسه داشته باشد.
4. مهاجرت‌ها و داده‌های نمایشی را اجرا کنید:

```sh
php artisan migrate --force
php artisan db:seed --force
```

5. برای اجرای محلی از `php artisan serve` استفاده کنید.

داده‌های نمایشی شامل چند بازی، یک جام نمونه، یک قانون جایزه‌ی ۱۰ ساعت بازی رایگان پس از ۱۰۰ ساعت بازی، یک نوشته‌ی بلاگ و صفحه‌ی درباره‌ی ما است.
